### ⚠️ 两个必须先纠正的前提错误

**错误 A：功率级不是 "分立 NMOS + EG2133"。**
本地原理图 `V3P驱动板最新版原理图.pdf` 的器件清单实测为：

```
FD6287T  ×1     ← 三相栅极驱动（U10 附近）
FD6287   ×1     ← 另一路三相栅极驱动（U10 下方，双电机 ×2 路）
WSD4070DN×13    ← 功率 NMOS（双电机 × 三相 × 上下桥 = 12 只，另有 1 处标注）
INA240A2PWR ×4  ← 电流检测放大器（双电机 × 每电机 2 相在线电流）
EG2133   ×0     ← 原理图中根本没有出现
```

所以原分析文档"分立 NMOS + EG2133"的说法**在驱动芯片型号上是错的**；"分立 NMOS"部分其实是对的（WSD4070DN 确实是分立功率管，不是 IPM/智能功率模块）。**正确的表述是：分立 NMOS + FD6287T/FD6287 三相栅极驱动。**

**错误 B（更要紧）：0.01Ω 分流电阻下的量程不是 ±16.5A，而是 ±3.3A。**
计算过程见第 5 节——`0.01` 被多乘了一次 10。这个错误会让"12A 电机能测 16.5A 所以够用"的结论完全反转：**0.01Ω 配置下根本测不到 12A。** 但原厂用户手册写明出厂就是 `10mR`，量程 ±3.3A——两者一致，说明**这是设计的固有事实，不是笔误**，需要使用者特别注意。

### 2.3 对使用者的影响（结论）

1. **同一块板子上出现 FD6287T 与 FD6287 属正常**——大概率是同一功能位（双电机两路）在不同批次用了不同封装/丝印，或 TSSOP20 与 QFN24 混用。**功能与引脚定义相同，逻辑一致。**
2. **EG2133 可以直接替换 FD6287T**（脚对脚、逻辑对逻辑），反之亦然。但要注意两点差异：
   - **耐压**：EG2133 为 300V，FD6287T 为 250V。**用 FD6287T 替换 EG2133 是"降额替换"**，母线电压必须 <250V（本板 12–24V 供电，余量极大，无实际风险）。
   - **VCC 下限**：FD6287T 要求 7V（JSMSEMI 版 8V）起，EG2133 只要 4.5V。若原设计 VCC 只有 5V，换成 FD6287T 会触发 UVLO 不工作。本板 VCC 由板上电源产生（TPS54302/BL9342 等），正常应为 10~15V，无此问题。
3. **实操结论**：V3P 这块板上，FD6287T / FD6287 / EG2133 **三者可互换**，不会改变 PWM 逻辑极性（都是 HIN 高有效、LIN# 低有效）。

**置信度：高**（两份原厂手册逐脚比对）。

## 3. 【最重要】FD6287T 的死区是"固定内置"还是"可由 MCU 外加"？

### 3.1 结论（直接回答）

**死区不会叠加。FD6287T 采用"取较大值"（max）逻辑，而不是"相加"逻辑。**

MCU 设的死区（STM32 TIM1 BDTR / ESP32 MCPWM dead time）与芯片内置死区的关系是：

```
最终栅极看到的死区 = max( MCU 设定值, FD6287T 内置死区 )
```

具体来说：

| MCU 设定死区 | 最终输出死区 | 说明 |
|--------------|--------------|------|
| 100 ns | **200 ns** | 被内置死区"兜底"，MCU 设小了没用 |
| 200 ns | **200 ns** | 相当 |
| 500 ns | **500 ns** | MCU 设大时**以外部为准**（芯片不叠加） |
| 1000 ns | **1000 ns** | 以外部为准 |

**所以：用 STM32 TIM1 BDTR 或 ESP32 MCPWM 去设 500ns 死区，栅极上看到的就是 500ns，不是 700ns。** 想设小于 200ns 的死区则无效（会被内置的 200ns 覆盖）。

### 3.2 依据（原厂手册 §10「死区功能」原文照录）

> "芯片内部设置了**固定的**死区时间保护电路。在死区时间内，高侧和低侧输出均被设置为低电平。所设置的死区时间必须确保一个功率管关断后，再开启另外一个功率管，有效防止产生上下功率管直通现象。**如果逻辑输入设置的外部死区时间大于芯片内部设置的死区时间，则以逻辑输入设置的外部死区时间为芯片输出死区时间；如果逻辑输入设置的外部死区时间小于芯片内部设置的死区时间，则芯片输出的死区时间为芯片内部设置的死区时间。**"

这段话是整个问题的决定性证据，语义非常明确：**外部 > 内部 → 用外部；外部 < 内部 → 用内部**。这是典型的"或"逻辑（取大），没有任何"相加"的表述。

配套的 §10 时序图显示 HIN / LIN# 输入交叠处标注 `DT`，HO / LO 输出之间也标注 `DT`，且 DT 宽度与输入交叠宽度一致——进一步印证是 max 关系。

§9「直通防止功能」的波形图同理：当 HIN 与 LIN# 同时为高时，HO 与 LO 被强制为低（图中标注"直通保护"），这是**独立于死区的第二道硬件互锁**。

### 3.3 对 MCU 侧的影响

- **STM32（TIM1/TIM8 BDTR）**：BDTR 的 DTG[7:0] 位设置死区。因为芯片是 max 逻辑，**你把 DTG 设成 0 也不会真的没有死区**——芯片内置的 200ns 会兜底。这其实是好事：即使固件漏配死区，硬件也不会直通。
- **ESP32（MCPWM）**：ESP-IDF 文档对 Dead Time 子模块的定义是——"**This submodule is used to insert extra delay to the existing PWM edges generated in the previous steps.**"（该子模块用于在之前步骤生成的 PWM 边沿上插入**额外**延时）。这是 MCU 内部对互补对的边沿处理；它产生的最终波形送到 FD6287T 输入端，再由 FD6287T 按 max 规则处理。**两级是"串联取大"，不是"相加"。**
  来源：[ESP-IDF MCPWM 文档](https://docs.espressif.com/projects/esp-idf/en/v5.3.1/esp32/api-reference/peripherals/mcpwm.html)
- **本板例程实测**：`3、stm例程资料` 各 FOC 例程的 `Hardware/pwm.c` 里**根本没有调用 `TIM_BDTRConfig`**（只有 STM32 标准外设库自身定义，未被应用代码使用），PWM 用的是 TIM2 三通道，`TIM_Pulse=0` 起步。也就是说**出厂例程完全没有配置 MCU 端死区，完全依赖 FD6287T 的 200ns 内置死区**。这从侧面印证了内置死区足够、且不叠加。

### 3.4 实践建议

- **不要**为了"保险"把 MCU 死区设得很大（比如 1~2µs），那会真的把死区拉到 1~2µs，导致低速时电流波形畸变、转矩脉动、效率下降。
- 推荐做法：MCU 端死区留 0 或设一个略小于 200ns 的值，让芯片内置的 200ns 生效即可；只有当你需要**大于 200ns** 的死区（例如换了更大 Qg 的功率管、或想降低 dv/dt）时，才通过 MCU 主动设大。
- **换管子时要重算**：WSD4070DN 的 Qg=28nC、Rg=0.8Ω，配合 FD6287T 的 1.5A/1.8A 驱动能力，开关时间约 12ns 级，200ns 死区余量充足。

**置信度：很高**（原厂手册 §10 有直接、无歧义的条文；且 EG2133 手册同样宣称"内建死区控制电路 + 闭锁电路"，属同类设计惯例）。

### 4.2 是否适合做 12A 级三相桥功率管？

**结论：完全适合，余量充足。**

- **电流**：连续 68A @25℃（35A @100℃），脉冲 144A。相对 12A 峰值电流有 **5.7×** 余量。
- **电压**：40V。本板输入 12–24V，考虑反电动势与开关尖峰，24V 系统下余量约 1.7×，**够用但不算宽裕**；若用 24V 以上母线或高反电动势电机需重新评估。
- **导通损耗**：按 12A 有效值、RDS(on) 4.5mΩ 估算，单管 P = I²R ≈ 144 × 0.0045 ≈ **0.65W**（25℃ 时），叠加 RDS(on) 随温度上升（约 1.5×），实际约 **1W/管**。DFN3.3×3.3 + 散热焊盘 + RθJA 60℃/W，**PCB 铜箔散热设计到位即可，无需额外散热器**。

### 5.2 传递函数

INA240 是电压输出型双向电流检测放大器：

```
VOUT = (VREF1 + VREF2)/2 + (VIN+ − VIN−) × Gain
     = VREF + (I × Rshunt) × 50
```

其中 VREF 为 REF1/REF2 引脚设定的偏置。手册说明两个 REF 引脚"没有功能差异"，接 0V~VS 之间任意电压。若 REF1=VS、REF2=GND（或经电阻分压），则 VREF = VS/2。

### 5.3 量程计算（⚠️ 这里必须纠正原分析文档的错误）

**题设**：VREF = 3.3V/2 = 1.65V，Rshunt = 0.01Ω，Gain = 50 V/V。

**正确计算**（先算分流电阻上的电压，再除以电阻）：

```
输出相对偏置的可摆动电压：ΔV = ±1.65 V
分流电阻上的差分电压：  Vsense = ΔV / Gain = 1.65 / 50 = ±0.033 V（即 ±33 mV）
流过分流电阻的电流：    I = Vsense / Rshunt = 0.033 / 0.01 = ±3.3 A
```

**结论：0.01Ω + 50V/V + 1.65V 偏置 → 理论量程 ±3.3A（峰峰值 6.6A）。**

> ❌ 原分析文档给出的 "±16.5A" 是错的。按它的算式 `1.65 / (50 × 0.01)` 结果其实是 3.3，写成 16.5 属于**把 10mR 误当成 1mR 多乘了一次 10** 的笔误。
>
> ✅ **交叉验证**：DengFOC V3P 原厂用户手册明确写：
> - "电流检测采样电阻 **10mR**（可更换成 1mR，支持部分航模电机）"
> - "电流检测电流范围 **±33A（1mR 采样电阻下）**"
>
> 用 1mR 反算：`1.65 / 50 / 0.001 = 33 A` ✅ 与手册**完全吻合**。
> 因此 10mR 对应的就是 `1.65 / 50 / 0.01 = 3.3 A`。**手册与计算互相印证，结论确定。**
>
> 来源：DengFOC V3P 用户手册 §1.4「硬件特性」（本地文件：`1、V3P到手资料/DengFOC V3P驱动板用户手册.pdf`，原文照录如下）
>
> ```
> 输入直流电压范围   12-24V
> 支持电机数        2
> 峰值电流          12A
> 电流检测采样电阻   10mR(可更换成 1mR, 支持部分航模电机)
> 电流检测电流范围   ±33A(1mR 采样电阻下)
> ```

### 5.4 ⚠️ 由此暴露的一个真实设计矛盾（重要提醒）

手册同时写着：

- 峰值电流 **12A**
- 电流检测采样电阻 **10mR**，量程 **±3.3A**（由手册给出的 1mR/±33A 换算）

**这意味着出厂 10mR 配置下，电流环只能测到 ±3.3A，却要驱动峰值 12A 的电机——电流采样会在 3.3A 就饱和削顶。**

这带来两个实际后果：

1. **电流环（力矩模式）在大电流下失效**：超过 ±3.3A 后 INA240 输出被钳在 0V 或 3.3V 附近（受输出摆幅限制，实际约 0.05V ~ 3.1V），FOC 的 Park/Clarke 变换会拿到失真的电流值，导致力矩控制失准甚至震荡。
2. **电流保护阈值**：基于采样值的过流保护最迟在 3.3A 就会触发（如果代码里设了软保护）。

**好在手册已给出解决方案**："可更换成 1mR，支持部分航模电机"——换成 1mR 后量程变成 ±33A，正好覆盖 12A 电机并有 2.75× 余量。**这正是本次核查第 6 问的意义所在。**

**置信度：很高**（TI 原厂手册 + V3P 原厂用户手册 + 独立算术，三方互证）。

## 6. 把分流电阻从 0.01Ω 换成 0.001Ω 的影响

### 6.1 量程变化

同一套公式，仅 Rshunt 变 10 倍：

```
I_full = VREF / (Gain × Rshunt) = 1.65 / (50 × 0.001) = ±33 A
```

| Rshunt | 理论量程（±1.65V 摆幅） | 手册/实际 | 对 12A 电机 |
|--------|------------------------|-----------|-------------|
| 0.01 Ω | **±3.3 A** | 出厂配置 | ❌ 严重不足，会削顶 |
| 0.001 Ω | **±33 A** | 手册标称值 | ✅ 余量 2.75× |

考虑 INA240 输出线性区的实际限制（`GND+50mV ≤ VOUT ≤ VS−200mV`，即 3.3V 供电下 0.05V ~ 3.1V），以 1.65V 为中心的**可用对称摆幅为 ±1.45V**：

```
实用量程 = ±1.45 / (50 × 0.001) = ±29 A
```

所以 1mR 下"理论 ±33A、线性可用约 ±29A"，均远大于 12A，**足够**。

### 6.2 对 12 位 ADC 分辨率的影响

**前提**：ESP32 内置 2 个 **12 位 SAR ADC**，共 18 个模拟通道。

来源：[ESP32 系列芯片技术规格书 §4.9.1](https://www.espressif.com/sites/default/files/documentation/esp32_datasheet_cn.pdf)

- 理论 LS B 电压（满量程 3.3V）：`3.3 V / (2^12 − 1) = 3.3 / 4095 = 0.806 mV`
- 折算到电流：`I_LSB = V_LSB / (Gain × Rshunt)`

| Rshunt | 1 LSB 对应电压 | **1 LSB 对应电流** | 满量程码值范围 |
|--------|----------------|---------------------|----------------|
| **0.01 Ω**（出厂） | 0.806 mV | **≈ 1.61 mA/LSB** | ±3.3A 用满 4095 码 |
| **0.001 Ω**（改装） | 0.806 mV | **≈ 16.1 mA/LSB** | ±33A 用满 4095 码 |

算式（0.001Ω）：

```
I_LSB = 0.806 mV / (50 × 0.001 Ω)
      = 0.000806 V / 0.05 V/A
      ≈ 0.01612 A  =  16.1 mA/LSB
```

**结论：换到 1mR 后，分辨率从 1.61 mA/LSB 退化到 16.1 mA/LSB，正好变差 10 倍。** 这是量程与分辨率的经典权衡——量程扩大 10 倍，分辨率必然下降 10 倍（AD 位数不变）。

### 6.3 更真实的精度评估（不能只看 12 位标称）

ESP32 的 12 位 ADC 实际精度远低于标称，必须纳入评估：

| 项目 | ESP32 实测规格（原厂手册 表 4-3 / 4-4） |
|------|------------------------------------------|
| DNL（差分非线性） | **−7 ~ +7 LSB** |
| INL（积分非线性） | **−12 ~ +12 LSB** |
| 有效测量范围 @Atten=3（12dB） | 150 mV ~ **2450 mV** |
| 总误差 @Atten=3 | **−60 mV ~ +60 mV** |
| 芯片间差异 | 默认 **±6%** |

来源：[ESP32 系列芯片技术规格书 表 4-3/4-4](https://www.espressif.com/sites/default/files/documentation/esp32_datasheet_cn.pdf)

由此推出的**实际可用精度**：

- **INL ±12 LSB** 折算电流：`12 × 16.1 mA ≈ ±193 mA`（1mR 时）。
  对比 0.01Ω 时：`12 × 1.61 mA ≈ ±19 mA`。
- **ADC 输入范围限制**：Atten=3 时有效上限 **2450 mV**，而偏置点 1.65V。**正向只剩约 0.8V 可用**（1.65V → 2.45V），对应 `0.8 / 0.05 = ±16A`；负向可用到 1.65V → 0.15V，对应 `1.5 / 0.05 = ±30A`。
  - 即 1mR 下**量程其实是不对称的**：正向约 +16A、负向约 −30A。
  - 对 FOC 三相电流采样而言，正负不对称会引入偶次谐波误差，**需要用 ADC 校准（esp_adc_cal）或软件标定修正**。
- **INA240 自身误差**（这部分很小，可忽略）：VOS ±25µV → 折算 ±0.5mA（1mR）/ ±5mA（0.01Ω）；增益误差 ±0.2%。

**综合建议**：

1. 0.01Ω 配置**只能用于小电流调试**（≤3A），不能用于 12A 电机的电流环。
2. 驱动 12A 电机**必须换 1mR**，否则电流环必然削顶。
3. 换 1mR 后，**不要期望 16.1mA/LSB 的精度**——考虑 INL 和 ADC 非线性，实际有效分辨率约为 **±100~200mA 量级**。
4. **强烈建议启用 ESP-IDF 的 ADC 校准驱动**（`esp_adc_cal`），可将 ±6% 的芯片间差异和 INL 误差显著降低；并在代码中对 1.65V 偏置做实测标定（而非直接用理论值），以消除偏置误差。
5. 若需要更高精度，考虑外置 16 位 ADC，或提高 Rshunt（但牺牲量程）——**这是三者不可兼得的三角**。

**置信度：很高**（TI 手册 + Espressif 原厂手册 + 算术推导；量程 ±33A 与原厂 V3P 用户手册完全一致）。
