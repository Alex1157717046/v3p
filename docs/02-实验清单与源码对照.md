### E1.6 改写说明（重要）

原设计：改死区寄存器 → 扫出"死区–THD"曲线。
**实际做不到**：板上一相只有 1 根 PWM（HIN 与 LIN# 短接），死区由 FD6287T 内部固定。

改写后仍能拿到**定量结论**：

| 做法 | 得到什么 |
|---|---|
| `exp07_gatedrive` mode 1 + 示波器探 GH/GL | **真实死区值**（应 ≈200 ns，FD6287T typ） |
| `exp06_deadtime`：`align` → `mode id` → `sweep 1` | **vd–id 曲线在零点出现台阶**，台阶高度 = 2ΔV = 2·(Td/Ts)·Vdc，反推 Td |
| `exp06_deadtime`：`comp 1` + 调 `td` | 补偿后台阶/过零畸变显著减小 → 验证 `ΔV = sign(i)·(Td/Ts)·Vdc` 模型 |

**这一阶段的设计要点**：所有闭环都建立在 `lib/v3plab/v3p_foc.h` 的 `FocMotor` 上
（采样 → Clarke → Park → PI → 反Park → SVPWM），六个实验只是换不同的外环与开关。

## 阶段 7 · 定点化移植（✅ 已实现，STM32）

目录：`stm32f103-foc/`（独立 PlatformIO 工程，board = bluepill_f103c8）

| 产物 | 说明 |
|---|---|
| `lib/focq15/foc_q15.h` | Q15 定点 FOC 库：饱和乘、sin/cos 查表+插值、Clarke/Park、min-max SVPWM、Q31 积分器 PI |
| `src/main.cpp` | STM32 固件：同一套 FOC 用**浮点**和**Q15**各实现一遍，用 DWT 周期计数器直接量出单次迭代周期数 |
| `tools/q15_selftest.cpp` | **在 PC 上跑**的量化验证：逐点对比 Q15 与浮点 |

### ★ 量化验证结果（实测，不是理论值）

```
① sin 查表 vs std::sin                 最大误差 0.014% 满量程
② Clarke + Park（Q15）vs 浮点           最大误差 0.021%
③ SVPWM（Q15）vs 浮点
     占空比最大误差                       0.008%
     线电压(占空比差)最大误差 ← 决定电流    0.009%
④ PI（Q15 vs 浮点，同一误差序列）        最大偏差 0.008%
```

### ★★ 定点化真正会踩的三个坑（本工程全部实际踩到并修好）

| # | 坑 | 现象 | 修法 |
|---|---|---|---|
| 1 | **Clarke 中间量溢出** | 平衡三相时 `ia+2·ib` 可达 √3 倍幅值，超出 Q15 → 饱和后 β 完全错（实测误差 22%） | 中间量用 32/64 位承载，**只在最后一步饱和** |
| 2 | **标度事故：母线电压 > 1.0** | 把 `1/0.7` 传进 Q15 被饱和成 1.0 → 占空比误差 15% | 统一用「**1.0 = Vdc/√3**」的归一化约定，根本不需要传 Vdc |
| 3 | **PI 积分器位宽与截断顺序** | 只用 Q15 存积分、且先除后移 → 小信号时增量被截断成 0，积分器"爬不动"（实测偏差 9%） | 积分器用 **Q31**，且**先左移再除** |

> 这三条正是 E7.1 步骤②⑤⑦要你写进"标度表"的东西 —— 现在它们是**实测结论**，不是别人的经验。
